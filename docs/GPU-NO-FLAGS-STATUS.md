# Default Metal desktop path

The GUI and CLI now both compile the guest GPU syscall `0x2002`. The host establishes the local Metal broker by default; the guest no longer needs a renderer selection flag. The GUI guest environment no longer injects `LIBGL_ALWAYS_INDIRECT=1`. The virtual DRM card supports the tested master/authentication exchange Aquamarine uses when it reopens the card.

In a disposable Arch root with no `RDMETAL_*`, `MESA_*`, `LIBGL_*`, or `GALLIUM_*` selector, both surfaceless and GBM `eglinfo` reported `rdmetal Metal (direct)`. A separate guest EGL triangle produced `RDMETAL_FIXTURE_DRAW result=0` in the host log, establishing an actual Metal draw. In isolated standalone Hyprland, EGL initialized, the broker capability query succeeded, and Hyprland entered its event loop. A metadata-only broker query returned the real IOSurface stride (14464 bytes) before first render.

Full desktop acceptance is still blocked. GBM asks for a dma-buf FD immediately after allocation; the current broker only exports a completed image. The probe returned `-EPERM` for op11 FD export, after which Aquamarine could not import a framebuffer and no `DRM_PRESENT` or compositor Metal draw occurred. Issuing that FD early without changing ownership is unsafe: the current guest state marks the image exported and rejects later draws. The virtual KMS import and present path also maps the carrier as CPU bytes; it does not yet present its IOSurface. Full systemd boot additionally needs the IOSurface to cross from the compositor process to the host-window owner without CPU frame staging.

Next gates are a carrier issued before draw with no readable surface right, a completed-fence publication step, IOSurface-backed KMS import/present with consumer release, and a cross-process host-window present path. Tests must cover stale/replayed FDs, pre-completion denial, buffer reuse, ordinary-format fallback counts, sustained frames, and login-to-desktop operation. The source branch should not be installed as the default driver until these pass.
