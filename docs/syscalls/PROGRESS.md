# Syscall compatibility progress

This file records bounded behavior that has been implemented and tested. A dispatch case or a successful boot is not proof of full Linux compatibility. The static inventory in `AUDIT.md` is a triage list and may lag later commits.

Current safety and refusal status is summarized in [`SAFEGUARDS.md`](SAFEGUARDS.md).

The isolated #81 `sync` safeguard replaces a host-wide Darwin sync call and
false Linux success with explicit `ENOSYS`. Its CLI build, disposable ARM64
probe, and private Arch login/D-Bus boot gate pass. This is a safe refusal,
not Linux durability compatibility. See [`SYNC.md`](SYNC.md).

The isolated #221 `execve` follow-up snapshots its bounded guest pathname
before host resolution. Its focused ARM64 error/self-exec probe, CLI build,
and private Arch login/D-Bus boot gate pass. See
[`EXECVE-PATH.md`](EXECVE-PATH.md).

The merged #286 `preadv2` follow-up replaces raw guest iovec passthrough
with checked bounded reads while preserving its ARM64 offset and flag ABI.
Its focused probe, CLI build, and private Arch login/D-Bus boot gate pass.
See [`PREADV2-GUEST-MEMORY.md`](PREADV2-GUEST-MEMORY.md).

The isolated #281 `execveat` path correction snapshots the bounded guest
pathname before resolution or execution. Its CLI build, eight-mode ARM64
probe, and private Arch login/D-Bus boot gate pass; it does not change the
existing executable, argv, or envp translation. See
[`EXECVEAT-PATH.md`](EXECVEAT-PATH.md).

## Integration baseline

- Base: `3e47e28` (`development` as tracked on 2026-11-18).
- Integration checkout: an isolated clone under `task-3/shimmy-syscall-integration`. The active development checkout contains unrelated work and is not used for these edits.
- Each syscall gets a separate worktree and branch. Merge only after a focused semantic test and source review. Preserve the exact tested subset and unresolved Linux behavior in the commit and this ledger.
