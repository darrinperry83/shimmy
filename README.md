# shimmy

Run Linux (Arch, aarch64) as a desktop on macOS — the Linux compositor (Hyprland or KDE
Plasma) renders through the **rdmetal** driver and is presented on screen by the shim's Metal
path, with mac apps owned by the compositor as native Wayland surfaces.

This repo is the whole project:
- **the shim** (in-repo): syscall translation, the Wayland server (`wlsrv.c`), input, the Metal
  present path, and the mac-window→Wayland-surface bridge.
- **`rdmetal/`** (submodule): the Mesa Gallium driver + DRM/GBM node, installed into the guest.
- **`scanout/`** (submodule): the WindowServer injection for direct-to-display present
  (macOS-version pinned).

## Install (streamlined — 2 commands)

```sh
git clone --recursive https://github.com/darrinperry83/shimmy.git
cd shimmy
./install.sh                 # builds the shim, bootstraps the Arch rootfs, installs the desktop + rdmetal
./run.sh                     # boots Hyprland (or: ./run.sh --desktop kde)
```

`install.sh` produces the `rootfs/` directory locally (the rootfs is **not** stored in git),
installs the desktop with the standard Arch package commands (`pacman -S hyprland` /
`pacman -S plasma`), and installs `rdmetal` as the default GL driver — no environment
variables needed to run.

## Layout

```
shimmy/             the shim + install.sh + run.sh
├── rdmetal/        (submodule) the driver
├── scanout/        (submodule) the injection
└── rootfs/         generated by install.sh (gitignored)
```
