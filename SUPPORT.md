# Support

shimmy is early-stage and community-supported. For help:

- Read the [README](README.md) and [ARCH_MIGRATION.md](ARCH_MIGRATION.md).
- Search existing [issues](https://github.com/darrinperry83/shimmy/issues) before opening a new one.
- Use the issue templates for bugs and feature requests.
- For private matters, use [SECURITY.md](SECURITY.md).

There is no commercial support or SLA.
